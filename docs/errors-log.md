# errors-log.md — Journal des erreurs & blocages

> Template vierge. Consigner ici **chaque** erreur, bug, blocage ou décision-correctif rencontré pendant le développement. Objectif : ne jamais réparer deux fois le même problème et garder une trace pour le client.
>
> Ajouter les nouvelles entrées **en haut** (la plus récente d'abord). Copier le bloc modèle ci-dessous.

---

## Modèle d'entrée (à copier)

```
### ERR-000 — [Titre court du problème]
- **Date** : AAAA-MM-JJ
- **Page / fichier** : (ex. contact.html, assets/css/style.css)
- **Gravité** : bloquant | majeur | mineur | cosmétique
- **Statut** : ouvert | en cours | résolu | contourné
- **Symptôme** : ce qui se passe (message d'erreur exact si possible).
- **Cause** : cause racine identifiée.
- **Solution** : ce qui a corrigé (ou le contournement appliqué).
- **Prévention** : comment éviter que ça se reproduise.
```
